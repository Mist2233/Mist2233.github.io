Const关键字

September 6, 2025 · Mao

const 的基本作用#

我能想起来的 const 作用：

  1. 标记常量。
  2. 标记只能“读取”而不能“修改”的类函数。
  3. 在参数引用时，标记不能修改的参数。

为什么推荐用 const 而不是 #define 来定义常量？#

我的理解：

  • const 比 #define 更智能。
  • #define 是机械的、文本意义上的替换，你举的例子相当于把所有的 b 都替换成 10，这会带来一些运算上的问题，比如优先级之类的。
  • const 更加智能。但是具体原理我也说不清楚，希望面试官补充一下。

更加详细的补充：#define 是预处理器在编译前做的简单文本替换，它不理解 C++ 的语法。而 const 是 C++ 语言本身的一部分。

  1. 类型安全：const 定义的变量可以识别类型，但是 #define 做不到。
  2. 作用域：const 遵循 C++变量作用的规则，但是 #define 不会，容易造成命名冲突。
  3. 调试方便：const 定义的变量是有名字的，调试时可以看到。
  4. C++特性兼容：const 变量可以取地址、作为引用传递。

总结一下就是： 在 C++ 中，尽可能用 const (或 enum) 来替代 #define，因为 const 更安全、更规范、更易于维护。

const 搭配指针使用#

const int* p;
int* const p;
const int* const p;

上面三种用法的区别是？

我认为，需要看 const 声明修饰的是指针本身，还是指针指向的内容：

  • const int* p 中，const 直接修饰 int，可以结合为 const int 所以表示指向的变量的类型为 const int，即“指向常量的指针”。(pointer to const)
    • 含义：不能通过 p 来修改其指向的值，但是 p 本身的值可以修改，即可以指向其他地址的变量。
  • int* const p 中，const 直接修饰指针 p，所以表示指针值不可变，即“常量指针”。(const pointer)
    • 含义：p 本身是常量，不能被修改，但是 p 指向的内容的值是可以修改的。
  • 而 const int* const p 结合了上述两种情况，表示“指针值为常量，指向的变量也为常量”。

const 和 & 结合#

面试官 (最终问题): 很好，你对 const 和指针的结合理解得很透彻。现在我们把你最早的回答串联起来。

你提到了 const 的第三个作用：“在参数引用时，标记不能修改的参数”。比如我们写一个函数：

void printVector(const std::vector<int>& vec) {
    // ... 打印 vector 的内容 ...
}

请结合我们刚刚讨论的知识，从效率和安全性两个角度，解释一下为什么在这里使用 const 和引用 & 是一个非常好的编程实践？

  1. 效率：使用引用传递参数，避免变量被复制，减少了内存的消耗。
  2. 安全性：使用 const 标记变量，可以防止原本的变量被修改，保证了安全性。

更详细、准确的回答： 1. 效率 (Performance):

  • 避免拷贝 (Avoiding Copies)：正如你所说，使用引用 & 传递参数，避免了对整个 vector 的深拷贝。如果 vector 非常大，拷贝操作会消耗大量的时间和内存，导致函数调用效率低下。引用传递实际上只传递了一个类似指针的东西，开销极小，是 C++ 中高效传递大型对象的首选方式。

2. 安全性 (Safety):

  • 函数契约 (Function Contract)：在参数前加上 const，相当于我们对函数调用者做出了一个承诺：“我这个 printVector 函数，向你保证，绝对不会修改你传进来的 vec。” 这让函数的意图变得非常清晰，调用者可以放心地把自己的数据交给你，而不用担心数据被意外篡改。
  • 编译器保护 (Compiler Protection)：这个 const 不仅仅是一个口头承诺，它更是受到了编译器的强制保护。如果在 printVector 函数内部，有任何代码试图修改 vec（比如 vec.push_back(1); 或者 vec[0] = 10;），编译器会直接报错，从根本上杜绝了无意中修改数据的可能性。
  • 扩大适用范围 (Wider Applicability)：const 引用参数还可以接收常量对象和临时对象 (右值)。如果函数签名是 void func(vector<int>& vec)（没有 const），那么你就不能把一个 const vector 或者一个临时创建的 vector 传给它，这会降低函数的通用性。

综合来说，const T& 是一种结合了C 指针式高效 (传递地址) 和值传递式安全 (不能修改原数据) 优点的一种“集大成”的参数传递方式，是 C++ 程序员工具箱里必备的利器。
