C++的三种访问权限修饰符

成员访问的三种权限 面试官： 在 C++ 的类（class）定义中，我们有 public, protected, 和 private 这三个关键字来控制成员的访问权限。 你能简单解释一下，这三种权限分别意味着什么吗？也就是说，什么样的代码可以访问被它们修饰的成员？ 回答： public 修饰的成员，可以被该类的对象、该类的子类成员，以及该类的其他成员访问。（最宽松） private 修饰的成员，只能被该类的其他成员访问，而不能被对象和子类成员访问。（最严格） protected 修饰的成员，可以被该类的其他成员和子类的成员访问，但不能被该类的对象访问。（介于 public 和 private 之间） Gemini 更好的概括： public: 类内、子类、类外（通过对象）都能访问。权限最开放。 private: 仅限类内访问。权限最严格，实现了完全的封装。 protected: 类内、子类可以访问，但类外不行。权限介于两者之间，专门为继承体系设计。 类继承的三种权限 面试官 (深入提问): 好的，你对成员访问权限很清楚。现在我们把这个概念和继承结合起来。 C++ 中，继承也有三种方式：public 继承、protected 继承和 private 继承。 class Base { public: int public_member; protected: int protected_member; private: int private_member; }; class Derived_Public : public Base { ... }; class Derived_Protected : protected Base { ... }; class Derived_Private : private Base { ... }; 请问，这三种不同的继承方式，会如何影响基类 (Base) 的成员在派生类 (Derived) 中的访问权限？ ...
