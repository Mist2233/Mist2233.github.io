using 声明和 using 指令 面试官： 在 C++ 中，using 关键字有多种用途。我们先来聊聊它最常见的两种用法：using 声明 (using-declaration) 和 using 指令 (using-directive)。 请问，下面这两行代码，它们分别属于哪一种？它们在作用和影响范围上，有什么本质的区别？ // 场景一 #include <iostream> void func1() { using std::cout; // 这是什么？ cout << "Hello"; } // 场景二 #include <iostream> #include <vector> using namespace std; // 这又是什么？ void func2() { cout << "World"; vector<int> v; } 回答： using std::cout 属于 using 声明，它只引入命名空间中的单个成员，作用在当前作用域中，适合局部使用。 using namespace std 属于 using 指令，它负责引入整个命名空间，作用在全局，但容易导致二义性问题。 面试官 (总结与肯定): 你说的完全正确。 1. using 声明 (using-declaration): using std::cout; 作用：将命名空间中的某一个特定的名字，引入到当前的作用域中。 粒度：非常精细，只引入你需要的那个名字 (cout)。 范围：遵循正常的作用域规则。如果在函数内部声明，就只在该函数内有效；如果在全局声明，就在整个文件内有效。 优点： 精确控制：只引入需要的符号，避免了不必要的命名空间污染。 解决二义性：如果不同命名空间有同名函数，using 声明可以明确指定你想要的版本，而不会像 using 指令那样导致冲突。 推荐用法：在 .cpp 文件的函数内部或文件作用域使用，是推荐的实践。 2. using 指令 (using-directive): using namespace std; ...
