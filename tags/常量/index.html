Const关键字

const 修饰变量 面试官： 看到你的简历上写着熟悉 C++，那我们来聊聊 const 关键字吧。它在 C++ 中有很多用途。 我的第一个问题是： 当 const 用于修饰一个变量时，它意味着什么？它和 C 语言中的 #define 宏定义常量相比，有什么主要的优势？ // 方式一 const int MAX_SIZE = 100; // 方式二 #define MAX_SIZE 100 回答： const 关键字修饰变量，表示这个变量是一个常量，不能被修改。 和 #define 宏定义常量相比，const 变量更加有下面的优势： 类型检查：const 是有类型的变量，编译器会进行类型检查，而 #define 是纯文本变量，没有类型概念，容易引发隐性错误——编译通过但运行出错。 作用域控制：const 类型的变量可以定义在局部作用域中，而 #define 是全局替换，容易产生命名冲突 调试支持：const 变量可以在调试器中查看它的值和地址，而 #define 变量在预处理阶段就被替换到，调试器无法识别。 取地址操作：const 变量可以取地址，而 #define 是文本替换，没有地址的概念。 跨文件访问：const 变量可以通过 extern 声明在多个文件中共享，而 #define 无法跨文件共享，只能重新定义。 当然，const 最主要的优势还是类型检查和作用域控制。 const 与指针结合 面试官 (继续提问): 好的，你对 const 修饰普通变量的理解非常透彻。我们来看它和指针的结合。 请你解释一下，下面这三种声明中，p 的类型有什么不同？分别都约束了什么东西不能被修改？ const int* p; // 1 int* const p; // 2 const int* const p; // 3 （提示：一个有用的技巧是“从右往左读”，或者看 const 在 * 的哪一边。） ...
