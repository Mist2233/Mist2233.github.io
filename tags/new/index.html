new 的两步过程、定位 new 操作 面试官： 我们知道，new 操作符用于在堆上分配内存并构造对象。比如 MyClass* p = new MyClass();。 其实，这个简单的 new 表达式，背后可以被看作是两个步骤的组合。你能描述一下这两个步骤分别是什么吗？ 另外，C++ 还提供了一种叫做 “定位 new (placement new)” 的特殊语法。它的形式是 new (address) Type(args)。你了解它是用来做什么的吗？它和普通的 new 有什么核心区别？ 回答： new 表达式可以看作这样两个步骤的组合： 第一步：分配内存。 第二步：在分配到的内存上构造对象，即初始化。 定位 new 操作，顾名思义，就是在一个确定的地址上构造对象，而不是自己分配内存。通过定位 new 构造的对象，不能调用 delete 销毁，需要手动析构。 面试官 (总结与肯定): 1. new 表达式的两步走 你说的完全正确。T* p = new T(args); 这个表达式，在概念上等价于： 分配内存 (Allocation)：调用一个名为 operator new 的函数，来分配一块足够大的、未初始化的裸内存。这个函数很像 malloc。 void* memory = operator new(sizeof(T)); 构造对象 (Construction)：在这块分配好的内存上，调用 T 类的构造函数来初始化对象。 T* obj = static_cast<T*>(memory); obj->T::T(args); // 伪代码，表示调用构造函数 2. 定位 new (placement new) 你的解释也堪称完美： ...
