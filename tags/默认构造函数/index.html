默认构造函数

default和delete

default 关键字强制生成默认构造函数 模拟面试开始 面试官： 我们知道，如果一个类我们不给它定义任何构造函数，编译器会自动为我们生成一个默认构造函数。类似的，编译器也可能会为我们生成拷贝构造函数、拷贝赋值运算符等。 在 C++11 之后，如果我们想显式地告诉编译器：“请为我生成一个默认的、最普通的版本”，我们可以使用 default 关键字。 请看下面这个例子： class MyClass { public: MyClass() = default; // 显式地要求编译器生成默认构造函数 MyClass(int val) : data(val) {} // 用户自定义了别的构造函数 private: int data; }; 我的问题是： 在这个例子中，MyClass() = default; 这一行代码，有什么实际意义？ 换句话说，如果我们删掉 MyClass() = default; 这一行，会发生什么变化？这个类还能通过 MyClass obj; 这种方式创建对象吗？为什么？ 回答： 当用户自己定义了一种构造函数时，编译器就不会自动生成默认的无参数的构造函数。 MyClass() = default; 确保无参数的构造函数存在。 如果删去这一行，那么 MyClass 这个类就无法通过 MyClass obj; 这种方式创建对象，因为编译器检测不到对应的构造函数。 而增加上这一行，可以使得程序可以在无参数的情况下创建新的对象，等到对其内容有要求时，再做修改。 面试官 (总结与肯定): 你说的没错。这个问题的核心在于 C++ 的一条规则： 一旦用户为类定义了任何一种构造函数（无论带不带参数），编译器就会“罢工”，不再自动生成默认（无参）构造函数。 所以，在你给出的例子中： 因为你已经定义了一个 MyClass(int val)，编译器就不会再自动生成 MyClass() 了。 如果我们删掉 MyClass() = default; 这一行，那么 MyClass 类就没有无参构造函数。此时，MyClass obj; 这样的代码就会编译失败，因为它找不到匹配的构造函数。 = default 的作用： MyClass() = default; 这一行，就是你（程序员）在向编译器明确地下指令： ...
